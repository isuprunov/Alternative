# Альтернатива Онлайн

Информационный сайт сообщества: единое пространство с расписанием собраний,
служениями, новостями и ресурсами. Реализован по техническому заданию.

**Стек:** React 19 + TypeScript + Vite, React Router 7. Без внешних UI-библиотек.

## Запуск

```bash
npm install
npm run dev      # запуск в режиме разработки → http://localhost:5173
npm run build    # проверка типов + production-сборка в dist/
npm run preview  # предпросмотр собранной версии
```

## Возможности

- **Главная** — верхний блок, блок «Сейчас / Далее» (определяет идущее и
  ближайшее собрание), ближайшие собрания, потребность в служащих, новости,
  ресурсы.
- **Расписание** — регулярные собрания, сгруппированные по дням недели;
  выделяются текущий день и ближайшее собрание.
- **Служения** — потребность в служащих с фильтрами (сегодня / завтра /
  ближайшие дни / по типу / только свободные) и кнопкой «Взять служение».
- **Новости** — лента с закреплёнными и важными объявлениями, отдельная
  страница новости.
- **Наши ресурсы** — карточки внешних ресурсов (ссылки открываются в новой
  вкладке).
- **Административная панель** (`/admin`) — редактирование собраний, служений,
  новостей, ресурсов и настроек без изменения кода.
- Адаптивность: левое меню на десктопе, бургер-меню с выезжающей панелью на
  мобильных; рабочая область ограничена по ширине.
- Серо-бело-стальная минималистичная тема, шрифт Inter.

## Архитектура данных

Контент загружается с бэкенда **Alternativa.Api** и там же сохраняется:

- `src/data/api.ts` — HTTP-клиент CRUD (`/api/*`), базовый адрес берётся из
  `VITE_API_URL` (см. `.env`, по умолчанию `http://localhost:5080/api`).
- `src/data/store.tsx` — контекст: загружает снимок `/api/data` при старте,
  мутации отправляет на сервер и применяет к локальному состоянию. Пока данные
  не загружены — показывается индикатор; при недоступности API — экран ошибки
  с кнопкой «Повторить».

Бэкенд должен быть запущен (см. `../Alternativa.Api/README.md`):

```bash
cd ../Alternativa.Api
docker compose up -d   # PostgreSQL на порту 5433
dotnet run             # API на http://localhost:5080
```

## Структура

```
src/
  components/   Layout (левое меню + бургер), Modal, иконки, блоки-карточки
  data/         store.tsx (слой данных), seed.ts (начальное наполнение)
  lib/          datetime.ts (расчёт «Сейчас/Далее», группировка, форматы)
  pages/        Home, Schedule, Services, News, NewsDetail, Resources, Admin
  types.ts      доменные типы
```
