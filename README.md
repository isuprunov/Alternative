# Альтернатива Онлайн

Сайт сообщества: расписание собраний, служения, новости и ресурсы.

---

## 🚀 Как запустить сайт (простая инструкция)

Ничего программировать не нужно. Просто выполните шаги по порядку.

### Шаг 1. Один раз установите программу «Docker Desktop»

Она сама запускает и сайт, и базу данных — вам не нужно ничего настраивать вручную.

1. Откройте страницу: **https://www.docker.com/products/docker-desktop/**
2. Нажмите кнопку скачивания для вашего компьютера (Windows или Mac).
3. Запустите скачанный файл и установите, нажимая «Далее» / «Next».
4. После установки **запустите Docker Desktop** (значок кита 🐳) и подождите,
   пока внизу слева не загорится зелёная надпись, что он работает.

> Этот шаг делается только **один раз**. В следующий раз сразу переходите к Шагу 2.

### Шаг 2. Откройте консоль (командную строку)

- **Windows:** нажмите `Win + R`, напечатайте `cmd` и нажмите Enter.
- **Mac:** нажмите `Cmd + пробел`, напечатайте `Terminal` и нажмите Enter.

### Шаг 3. Перейдите в папку проекта

Скопируйте строку ниже, вставьте в консоль и нажмите Enter.
(Замените путь на тот, куда вы скачали проект, если он другой.)

**Windows:**

```
cd C:\Users\ВашеИмя\Alternative\Alternativa.Api
```

**Mac:**

```
cd ~/Alternative/Alternativa.Api
```

> 💡 Как найти путь: откройте папку проекта в проводнике, зайдите внутрь папки
> `Alternativa.Api` и скопируйте путь из адресной строки.

### Шаг 4. Запустите сайт

Скопируйте эту строку, вставьте в консоль и нажмите Enter:

```
docker compose up --build
```

Пойдёт много текста — это нормально. Дождитесь, пока строчки перестанут
появляться и всё «успокоится» (обычно 1–3 минуты в первый раз).

### Шаг 5. Откройте сайт

Откройте браузер (Chrome, Edge и т.п.) и зайдите по адресу:

```
http://localhost:8080
```

Готово — сайт работает! 🎉

---

## ⏹ Как остановить сайт

Вернитесь в консоль, где всё запущено, и нажмите на клавиатуре:

```
Ctrl + C
```

Либо просто закройте окно консоли.

---

## ❓ Если что-то не получилось

- **Пишет «docker: command not found» или «docker не является командой».**
  Значит, Docker Desktop не установлен или не запущен. Вернитесь к Шагу 1,
  запустите Docker Desktop и дождитесь зелёного индикатора.
- **Страница `http://localhost:8080` не открывается.**
  Подождите ещё минуту (сайт мог не успеть запуститься) и обновите страницу.
- **Хотите запустить заново «с нуля».** Остановите (`Ctrl + C`) и снова
  выполните команду из Шага 4.
